# lib/intent-dispatcher/

Slash/深链意图分发 schema、解析与执行（schema 纯函数；执行经动态 import 接应用 store）。

| 文件        | 职责                                                                                                                                                                                                                                                                                                                                                                 |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schema.ts` | 意图 payload Zod schema 与 `parseIntentUrl`（oauth 为 `exchange`+`state`）；`redactIntentUrl` 日志脱敏                                                                                                                                                                                                                                                               |
| `index.ts`  | 解析与路由门面（`dispatch` 返回成功态，支持接收页面层已解析 intent，避免重复解析）；OAuth 回调须携带本机发起时生成的 `state`（一次性、5 分钟有效，错误/过期/重放即拒绝），经控制平面 `exchange` 兑换后先验沙箱列表再落 token 并建 Cloud 档案；日志统一经 `redactIntentUrl` 脱敏；toast 文案经 `IntentMessages` 由调用方按当前语言注入（`intentDispatcher` 命名空间） |
