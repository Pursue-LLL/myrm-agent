# lib/constants/

前端跨模块常量 SSOT（路径、artifact 类型、代码块主题、长耗时请求超时）。

| 文件                 | 职责                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `paths.ts`           | 应用路由与 API 路径常量                                                                        |
| `artifact.ts`        | 工件 MIME/类型枚举                                                                             |
| `codeblock-theme.ts` | 代码高亮主题 token                                                                             |
| `requestTimeouts.ts` | 长耗时同步请求的客户端与 Next 重写代理共用超时上限；被 `next.config.ts` 引用，必须零运行时依赖 |
