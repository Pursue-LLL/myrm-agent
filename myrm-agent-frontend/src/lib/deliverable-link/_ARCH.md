# lib/deliverable-link/

## 架构概述

解析助手回复中的交付物引用，供 Markdown 链接化使用。前端专用纯逻辑，工作区路径在渲染时经 `/files/browse/content` + `chat_id` 解析。

## 文件清单

| 文件                           | 地位 | 职责                                                              | I/O/P |
| ------------------------------ | ---- | ----------------------------------------------------------------- | ----- |
| `parseDeliverableReference.ts` | 核心 | 解析行内代码/Markdown 链接中的交付物引用为判别联合类型，无法识别返回 `null` | ✅    |

## 依赖

- `@/lib/api` — 工作区路径解析端点
- 父模块 [`../_ARCH.md`](../_ARCH.md)
