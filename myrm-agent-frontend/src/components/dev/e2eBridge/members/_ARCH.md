# members/

## 架构概述

`window.__MYRM_E2E_CHAT__` 的成员，按职责分成 8 个分组工厂，由 `createE2eChatBridge.ts` 汇合；一个成员只能出现在一个分组里（同名成员后者覆盖前者，由 `../__tests__/e2eChatBridgeMembers.test.ts` 检查）。
Python 端开发工具（`myrm-agent/scripts/dev/lib/cdp_chat/`）按成员名调用这些成员。
