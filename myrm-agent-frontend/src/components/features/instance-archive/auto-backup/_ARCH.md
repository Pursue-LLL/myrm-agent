# features/instance-archive/auto-backup/

## 架构概述

定时自动备份卡：开关、频率、保留份数、备份文件夹、立即备份与已存副本。后端策略见 server `app/services/instance_archive/auto_backup/`，客户端协议见 `src/services/instanceAutoBackup.ts`。挂载在上一级 `InstanceArchivePanel`，位于导出卡与导入卡之下。

设计约束：

- **默认关闭，仅服务端声明支持（本地/桌面）时渲染**：云端沙箱与读不到状态时整张卡不出现。
- **如实说明局限**：文案明确「未加密、不含登录与密钥、默认位置在本机」，并指出与「记忆云端备份」的范围差异；状态读「最近一次备份」，不写「已验证」。
- **只通过既有恢复流程恢复**：已存副本列表只读，提供「如何恢复」指引，不提供恢复按钮，也不显示文件名。
- **关闭后仍可找到已有副本与所选文件夹**：关闭只收起状态、频率、份数与立即备份；存在副本，或用户选过自定义文件夹时，文件夹行与副本列表保持可见。所选文件夹读不到（拔出的硬盘、离线的共享盘）、因而列不出副本时同样保持可见：它是更换文件夹的唯一入口，开启被拒后用户由此改选或恢复默认。只有从未配置过（默认文件夹、无副本）的卡片只显示开关与局限说明。
- **失败只显示本地化文案**：保存失败与运行失败都按稳定错误码映射（`lib/instance-archive/errors.ts`），服务端措辞永不展示。
- **进度由服务端报告**：备份进行中每 2 秒轮询，直到服务端报告结束，界面不猜测结果。
- 文案命名空间为 `instanceArchive.auto`（六语言 monolith `locales/*.json`）；连续失败的全局提示见 `hooks/globalEvents/backupAlertToast.ts`，直达本卡片锚点 `#auto-backup`。

`../InstanceArchivePanel` → 本目录 → `../ArchiveErrorNotice`、`@/services/instanceAutoBackup`、`@/services/instanceArchive::archiveErrorCode`（仅取稳定错误码）、`@/lib/instance-archive/format`、`@/lib/desktopBridge`。本目录不依赖导出/导入流程的组件与状态。
