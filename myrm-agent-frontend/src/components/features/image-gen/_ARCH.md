# image-gen/

## 架构概述

图像生成任务 UI 与结果展示。

## 文件清单

| 文件                       | 地位 | 职责                                                                                                                                                                  | I/O/P |
| -------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| `ImageResultCard.tsx`      | 核心 | 图像生成结果卡片：图片以 `media://` 引用到达、渲染时才解析成后端地址；预览 / 下载 / 灯箱与「编辑此图」按钮（把收到的引用原样交回）                                    | ✅    |
| `useEditGeneratedImage.ts` | 核心 | 「编辑此图」动作：把一张生成图作为附件放进输入框（附件记 `mediaId`，由消息构造器转成模型可直接传给图像工具的 `media://<id>`）并预填编辑指令；所有展示生成图的卡片共用 | ✅    |

## 依赖

- `@/store/*`、`@/services/*`、`@/components/primitives/*`
- `@/lib/api-url`（`getStorageUrl`）、`@/lib/mediaReference`、`@/lib/chat/focusMessageInput`
- 父模块 [`features/_ARCH.md`](../_ARCH.md)
