# files/

## 架构概述

文件展示层的共享图标组件。根据扩展名返回对应图标与配色，供文件树、文件预览与 diff 视图复用。

## 文件清单

| 文件               | 地位 | 职责                                                     | I/O/P |
| ------------------ | ---- | -------------------------------------------------------- | ----- |
| `FileTypeIcon.tsx` | 核心 | 按扩展名/目录态渲染文件图标与配色（代码/文档/图片/压缩/音视频分类） | ✅    |

## 依赖

- `lucide-react` — 图标基元
- `@/lib/utils/classnameUtils` — 类名合并
- 父模块 [`../_ARCH.md`](../_ARCH.md)
