# components/features/skills/alignment 模块架构

## 架构概述

前置需求结构化对齐组件包。在 Agent 开始流式生成复杂 HTML、课件、图表与看板前，主动弹出结构化偏好卡片（基于 AskQuestion 协议），对齐视觉配色、版面形态与交互深度，并提供「先规划再执行 (Plan Before Execute)」门禁开关，彻底解决用户大白话描述导致代码方向跑偏返工的痛点。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `alignmentTypes.ts` | 核心 | 结构化问题、偏好选项与对齐结果提交 DTO 契约 | ✅ |
| `PreFlightAlignmentModal.tsx` | 核心 | 前置对齐模态框、结构化多选题卡片、规划门禁开关与约束 Prompt 实时编译 | ✅ |
| `index.ts` | 门面 | 统一导出公共组件与类型定义 | ✅ |

## 设计原则

- **前置消除不确定性**：将开放模糊的自然语言要求结构化为离散选项，降低模型幻觉与方向偏差。
- **规划门禁**：通过「先规划再执行」开关强制约束模型输出线框与步骤，提升可控性。
- **纯矢量与无 Any**：全量使用 Lucide SVG 矢量图标，严禁原生 emoji 与 `any` 类型。
