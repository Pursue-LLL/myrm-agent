# commerce 模块架构

## 架构概述

消费额度闸前端组件集合，提供账本流水状态芯片。

## 核心文件

| 文件                    | 地位 | 职责                                                                                                                                                | I/O/P |
| ----------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| `SpendReceiptBadge.tsx` | 核心 | 账本流水状态小芯片，展示商户、金额、状态与条目哈希记录标识；状态文案与哈希提示取自 `commerceReceipt.*`，`__tests__/SpendReceiptBadge.test.tsx` 覆盖 | ✅    |
| `index.ts`              | 门面 | 模块对外聚合导出门面                                                                                                                                | ✅    |
