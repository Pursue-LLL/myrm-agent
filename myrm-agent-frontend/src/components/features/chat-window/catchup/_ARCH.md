# chat-window/catchup/

会话 catch-up 摘要收件箱 UI：列出用户离开期间发生了事的会话（已完成回复 / 仍在运行 / 等待审批 / 失败或被停止）。「已读」语义是用户在场水位线（服务端 `last_read_at`），由 `hooks/chat/usePresenceReadMark` 盖章。

| 文件                   | 职责                                                                                                                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CatchupInbox.tsx`     | 收件箱：挂载与 SSE 事件（`subagents_updated` / `cron_updated` / `app_resync_required`，以及仅在**阶段切换**时触发的 `run-digest-updated`）和当前会话切换后去抖重拉；不列出正在查看的会话；忽略后重拉补位（列表有上限） |
| `CatchupBriefCard.tsx` | 单条摘要卡：五种状态（含 stopped）、提示与回复预览、需求编码本地化、工具只显示调用次数不暴露工具标识；运行中/等待审批的会话不提供忽略（忽略只会被立即重新列出）                                                        |
