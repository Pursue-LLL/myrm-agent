# XiaoMo Unified Natural Language Control Center

## 架构定位

小莫全能自然语言控制中枢（XiaoMo Control Hub）为全系统级统一自然语言与多 Agent 操作中枢。用户可通过快捷键（`Cmd+J` / `Ctrl+J`）或常驻 HUD 胶囊唤起对话浮层，直接以口语或语音下达系统管理指令（如新建项目、汇总任务进度、终止闲置后台进程、系统健康诊断等），由系统智能解析并直接代劳执行，返回结构化执行卡片与后继建议。

## 模块清单

| 文件 | 职责 | 行数/规范 |
|---|---|---|
| `SystemAssistantModal.tsx` | 自然语言控制弹窗：语义化 `<dialog>`，支持文字/语音输入、推荐指令点选、结构化动作卡片与后续跟进，显示系统健康度与运行任务数 | `< 300` 行，零 `any`，Tailwind 语义类 |
| `SystemAssistantTrigger.tsx` | 全局常驻启动器与快捷键监听器：监听 `Cmd+J` / `Ctrl+J`，提供常驻浮动胶囊入口，消除 Dead Feature Path | `< 100` 行，无原生 emoji |
| `index.ts` | 门面导出文件：统一导出模态弹窗与触发器组件 | 统一入口 |
| `_ARCH.md` | 本模块架构说明与文件职责索引 | 遵循架构规范 |

## 意图与交互流程

1. **指令唤起**：用户按 `Cmd+J` 或点击左下角浮动胶囊打开控制中心；
2. **意图调度**：输入口语化指令或点击推荐胶囊，调用 `POST /api/v1/system-assistant/command`；
3. **结构化呈现**：返回卡片渲染意图分类、执行状态、关键沙箱/项目元数据与快捷后继动作按钮。
