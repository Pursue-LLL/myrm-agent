# Fingerprint Studio & Communication Parity Architecture

## 职责边界
- `fingerprintStudioTypes.ts`: 宿主机硬件指纹、健康度遥测、智能体工坊资产与全模态通讯平权强契约；
- `deviceFingerprintEngine.ts`: 纯函数计算宿主机标签、硬件徽章、设备健康加权分、哈希指纹及企业合规审计留痕；
- `useFingerprintStudioStore.ts`: Zustand 状态机总线，管理多宿主机设备池、工坊四维资产一站式收敛与实时通话生命周期；
- `HostFingerprintBadge.tsx`: 差异化宿主机硬件指纹徽章，支持 mini 与 expanded 模式及悬浮遥测详情，消除同质化混淆；
- `UnifiedAgentStudioModal.tsx`: 一站式收敛 Agent 身份、专属技能、数据连接器与专属知识库，彻底打破入口割裂；
- `FullModalityParityCallHUD.tsx`: 个人与企业模式全模态平权实时音视频通话悬浮条，企业模式自动附加审计存证链。
