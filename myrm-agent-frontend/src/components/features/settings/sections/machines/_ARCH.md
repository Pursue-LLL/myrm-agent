# settings/sections/machines 模块架构

## 架构概述

自托管机群全局监控看板与远程人机同屏接管套件。对标 Cursor Dashboard "My Machines" 与 Live Takeover 交互体系，管理接入的物理机与私有算力节点，提供 1 键复制单行命令接入向导、机群拓扑卡片网格、实时 CPU/内存/磁盘/活跃任务多维遥测仪表盘，以及 60 FPS 实时屏幕画中画与悬浮接管控制台，彻底打通复杂反爬与滑块验证的人机协同闭环。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `machinesTypes.ts` | 核心 | 机群节点、遥测指标、平台枚举、注册令牌与接管会话强类型契约 | ✅ |
| `machinesService.ts` | 核心 | 机群列表查询、多平台一键命令生成、人工接管与交还状态调度 | ✅ |
| `ConnectMachineModal.tsx` | 组件 | 极简 3 步一键接入向导：macOS/Linux/Windows 平台切换、单行脚本生成与心跳握手探测 | ✅ |
| `MyMachinesSection.tsx` | 组件 | 机群全局监控看板：节点网格、平台徽标、实时指标仪表盘与活跃任务状态 | ✅ |
| `LiveTakeoverDrawer.tsx` | 组件 | 实时屏幕流画中画 + 悬浮「接管/交还」控制台，琥珀色接管状态边框与鼠标透传 | ✅ |
| `index.ts` | 门面 | 统一导出公共类型、服务与交互组件 | ✅ |

## 设计原则

- **3 秒接入原则**：自动生成平台专属的单行注册命令，用户在终端粘贴运行即在 3 秒内建立加密握手并点亮在线指示灯。
- **人机无缝接管**：当智能体遇到反爬或复杂验证码卡点时，用户可一键人工接管控制，操作完毕后一键交还智能体继续自主调度。
- **纯矢量与零 Any**：全量使用 Lucide SVG 矢量图标，严禁原生 emoji 与 `any` 类型。
