# settings/sections/knowledge/ima/

## Overview

Settings → Wiki 的「腾讯 ima 知识库」导入卡：单卡片状态机（连接 → 选择知识库 → 导入中 / 已暂停 / 已是最新），所有界面状态都由服务端 `ImaStatus` 派生，刷新页面、多窗口、后台运行都不会让卡片停在已过期的步骤。服务端只返回状态码与计数，不返回文案；本目录把每个码映射到 `settings.wiki.ima.*` 双语（六语言）文案，未知码回退为通用文案，原始码与服务端 message 永不上屏。

## File Index

| File                 | Role | Description                                                                                                                                                                                                                                                                                                                        |
| -------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ImaSourceCard.tsx    | UI   | 卡片外壳与全部用户动作编排：按 `deriveImaView` 切换四屏；失败按 `errorKey` 显示为表单内一行或 toast；已连接即可断开（含选库步骤，连错账号无需先导入），断开需二次确认；报告弹窗仅在打开时挂载（每次从第一个非空分桶开始）                                                                                                          |
| ImaConnectForm.tsx   | UI   | Client ID + API Key 表单（首次连接与 ima 拒绝旧密钥后的重连共用），附 ima 官方凭据页外链（新窗口打开）；密钥只存在本地 state，连接失败保留输入便于改正，成功后随表单卸载                                                                                                                                                           |
| ImaLibraryPicker.tsx | UI   | 读取账号下的知识库并勾选、是否同时导入笔记；只把 ima 仍列出的 id 提交（服务端同样丢弃未知 id）；编辑已有同步时可取消                                                                                                                                                                                                               |
| ImaSyncPanel.tsx     | UI   | 同步中 / 已暂停 / 已是最新：阶段文案、首次导入进度条、结果计数（已导入 / 待导入 / 失败 / 已跳过 / 内容已简化 / 你已移除 / ima 中已删除，计数只含当前所选范围）、「立即检查」与下次自动检查时间、暂停继续、「编译」（带数量与字数说明，须用户点击；并按共享自动编译开关与首次导入进度说明后续文档如何编译）、内部故障提示、明细入口 |
| ImaReportDialog.tsx  | UI   | 导入明细：需要关注 / 内容已简化 / ima 中已删除三个分桶；每行用白话说明原因（码 → 文案），失败项可一键重试；服务端每个分桶最多返回 200 条，列表短于计数时明确提示「仅显示前 N 项」                                                                                                                                                  |
| useImaSync.ts        | Hook | 状态读取与轮询（仅在同步活跃且标签页可见时每 4 秒一次，空闲/暂停即停；点「立即检查」后额外观察 60 秒（再次点击重新计时），让用户看到结果而非静止画面）、全部动作返回 `{ok, errorKey}` 而不抛出；按 agent 范围隔离，切换范围不会显示别的库的状态                                                                                    |
| imaCopy.ts           | Core | 唯一认识 ima 状态码 / 原因码 / 保真说明码 / 媒体类型码的地方：视图与同步模式派生、进度与计数口径、是否轮询、能否「立即检查」、自动编译说明键、码 → locale key（未知回退通用文案）、字数格式化                                                                                                                                      |
