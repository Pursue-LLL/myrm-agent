# settings/default-model/

默认模型 Section 子组件：启用模型选择、温度、kwargs 编辑。

| 文件                     | 职责                                                       |
| ------------------------ | ---------------------------------------------------------- |
| `EnabledModelSelect.tsx` | 启用模型选择；OpenCode Contributor 选中时展示 consent 提示 |
| `TemperatureSlider.tsx`  | 温度滑块                                                   |
| `ModelKwargsEditor.tsx`  | 模型 kwargs JSON 编辑                                      |
