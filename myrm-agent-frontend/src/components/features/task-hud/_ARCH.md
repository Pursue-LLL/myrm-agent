# task-hud 模块架构

## 架构概述

抗上下文压缩会话任务持久化 HUD 挂载器与状态隔离前端组件库（Roadmap ⑨ Item 31）。
展示当前进行中步骤、加权总进度条以及可展开的多步 Checklist 状态机，保障在长对话上下文蒸馏压缩或热重载时任务坐标系永不丢失。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `taskHudTypes.ts` | 协议 | 任务状态（pending/in_progress/completed/failed）、子任务模型与 HUD 数据契约 | ✅ |
| `TaskHudOverlay.tsx` | 组件 | 交互式抗压缩悬浮任务顶栏 HUD，展示当前进行中任务、总进度条、展开多步 Checklist 与就地状态切换 | ✅ |
| `index.ts` | 门面 | 统一导出组件与协议类型 | ✅ |

## 契约要点

- **抗压缩受保护状态展示**：显著呈现「抗压缩 · 任务状态受保护」徽章，消除用户长程任务失忆焦虑；
- **状态联动**：与 `useTaskHudStore` 深度绑定，支持热重载（/reload）与跨会话切换自适应同步；
- **可访问性与代码质量红线**：语义化 `<section aria-label="...">` 容器，单文件严格低于 400 行，零 `any`，零原生 emoji。
