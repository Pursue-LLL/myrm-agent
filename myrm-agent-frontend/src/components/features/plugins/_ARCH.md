# plugins/

## 架构概述

Agent Plugins 1.0.0 插件导入向导 UI：上传 ZIP → 组件级预览（技能安全扫描/超长标记/同名冲突标记/诊断）→ 逐项决策 → 确认导入并绑定 Agent。
