# features/fleet-telemetry/

## 架构概述

分布式机队节点六态精细化健康遥测与排障定位视图组件。解决多机部署中粗粒度「连接失败」报错的痛点，精细区隔在线、物理离线、凭据失效、上游模型欠费/超限、守护停止与沙箱异常六维状态，并提供五级探针自检可视化排障弹窗。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `index.ts` | 门面 | 统一导出机队六态徽章与自检诊断弹窗 | ✅ |
| `FleetNodeSixStateBadge.tsx` | 组件 | 节点六态精细化微徽章：在线/离线/配置错误/Provider 欠费/守护停止/沙箱损坏，支持一键打开诊断弹窗 | ✅ |
| `FleetDiagnosisDialog.tsx` | 组件 | 五级渐进式自省排障定位视窗：呈现物理网络、凭据鉴权、网关守护、沙箱执行器与模型配额五级探针详情与行动建议 | ✅ |
| `__tests__/FleetNodeSixStateBadge.test.tsx` | 测试 | 六态微徽章渲染状态映射、欠费状态高亮文案与排障弹窗交互单元测试 | ✅ |
