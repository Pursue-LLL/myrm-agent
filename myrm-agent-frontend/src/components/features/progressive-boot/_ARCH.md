# 零阻断平滑启动与渐进式能力披露套件架构设计 (_ARCH.md)

## 1. 业务痛点与设计哲学
- **痛点**：传统智能体客户端在冷启动阶段往往充斥着密集的阻断式弹窗（更新提示、新功能导览、授权确认），且首页堆砌了大量类似“QQ 秀”的繁琐连接器、配置滑块与插件图标，给初次使用的用户造成极大认知负担与挫败感；
- **核心哲学**：
  1. **零阻断平滑启动 (Zero-Interruption Boot)**：启动阶段 1 秒内直接呈现核心极简对话与即席任务输入框，绝对禁止弹出任何强侵入式全屏 Modal；
  2. **后台静默就绪 (Silent Background Daemon)**：路由网关、沙箱容器、技能工具网格、MCP 桥接器与分层记忆 5 大核心服务在后台毫秒级静默探活与待命；
  3. **阻断弹窗静默拦截器 (Popup Suppressor)**：第三方组件企图触发的弹窗被自动转换为轻量“静默通知”存入后台通知箱，用户无需打断手头心流；
  4. **渐进式能力披露 (Progressive Disclosure)**：提供三级披露档位：
     - `minimal` (极简稳健档)：极简输入流与高频任务入口；
     - `standard` (标准生产档)：按需披露当前会话依赖的技能与进度卡片；
     - `expert` (底层专家档)：全量展开 MCP 外部连接器拓扑与沙箱遥测参数。

## 2. 状态机与架构流
```
           [ 应用冷启动 / 页面加载 ]
                       │
                       ▼
       ┌───────────────────────────────┐
       │   ZeroInterruptionBootContainer│
       │   - 0 侵入弹窗                │
       │   - 1 秒直达极简对话          │
       └───────────────┬───────────────┘
                       │
       ┌───────────────┴───────────────┐
       ▼                               ▼
[ 后台静默探活 (Silent Services) ]  [ 弹窗拦截器 (Popup Suppressor) ]
- 智能网关 / 安全沙箱              - 拦截冷启动期侵入式弹窗
- 技能网格 / MCP Bridge            - 转存为静默通知箱中的非阻断消息
- 分层向量记忆                     - 右上角药丸徽标轻提示
                       │
                       ▼
          ┌───────────────────────────┐
          │  ProgressiveDisclosureDrawer│
          │  - minimal / standard / expert 披露档位切换
          │  - 查看静默通知与服务健康矩阵
          └───────────────────────────┘
```

## 3. 文件组织
- `progressiveBootTypes.ts`：披露级别、静默服务健康契约、静默通知模型与 Store 规范；
- `useProgressiveBootStore.ts`：Zustand 响应式状态机，管理档位、抽屉显隐、服务探活与弹窗拦截；
- `SilentDaemonStatusBadge.tsx`：极简非侵入药丸徽标，无感展示后台探活状态与静默通知计数；
- `ProgressiveDisclosureDrawer.tsx`：渐进式披露控制抽屉，支持档位调整与静默通知处理；
- `ZeroInterruptionBootContainer.tsx`：零阻断平滑启动一体化容器；
- `index.ts`：模块统一导出。
