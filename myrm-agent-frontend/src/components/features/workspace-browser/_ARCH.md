# workspace-browser/

## 架构概述

工作区内嵌浏览器预览与检查器联动。有两个使用方：侧栏工作区视图（`layout/ChatSidebarContent`）与辅助工作台的文件页（`workbench/tabs/WorkbenchFiles`），二者共用同一套目录树、实时刷新与预览。

## 文件清单

| 文件                        | 地位 | 职责                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `WorkspaceDialogs.tsx`      | 组件 | 工作区文件操作确认对话框（删除确认、移动目标）；Escape 只取消对话框本身                                                                                                                                                                                                                                                                                                                                                 |
| `WorkspaceFileBrowser.tsx`  | 核心 | 沙箱文件树浏览器：展开/收起、右键菜单与写操作入口；扫描进行中保留已有目录树（只有还没有任何内容时才显示转圈），扫描失败只显示本地化提示、不透出服务端原文；顶部名称把会话自己的工作区文件夹（`chat_<chatId>`）显示为用户语言的「本次对话的工作区」；未扫描到的文件夹（`children: null`）展开时经 `onLoadChildren` 加载，失败以本地化提示并收起；目录右键「AI 整理」或「设为项目根目录」→ 联动聊天与 Project Scoped 边界 |
| `WorkspaceFileTree.tsx`     | 组件 | 目录树行（递归）：文件夹箭头/加载中转圈、图标、大小、@ 引用（与行按钮并列的独立按钮）、行内重命名；只做展示，数据与操作全部来自属性                                                                                                                                                                                                                                                                                     |
| `WorkspaceContextMenu.tsx`  | 组件 | 右键菜单（重命名/移动/删除；目录另含 `onOrganize` 与 `onSetProjectRoot` 入口）；贴近点击位置并保持在视口内，点击任意处或 Escape 关闭                                                                                                                                                                                                                                                                                    |
| `WorkspaceFileOps.tsx`      | 组件 | 上传（拖放与按钮）、新建目录、行内重命名、`useWorkspaceFileOps` 状态                                                                                                                                                                                                                                                                                                                                                    |
| `WorkspaceFilePreview.tsx`  | 组件 | 选中文件内联预览；文本走行号编辑器与内嵌 Inline Diff 审查，编辑状态来自 `useWorkspaceTextEditor`，服务端判定不可编辑的文件显示只读提示且不出现编辑入口；富媒体委托 `RichMediaFilePreview`；有保留的未保存文字时以编辑态打开；关闭预览或退出编辑时若有未保存编辑，应用内对话框选保存 / 放弃 / 留下（文件已变则无保存）；Ctrl/Cmd+S 在预览所在面板被隐藏（工作台切到终端标签）时不响应；文件读不出来只显示本地化提示      |
| `WorkspaceTextViews.tsx`    | 组件 | 文本预览的两种视图：只读行号代码 `LineNumberedCode`（自动换行：换行的长行占多行，其后的行号与正文行错开）与行号编辑器 `LineNumberedEditor`（不换行，行号与正文共用同一行高 `leading-5`，逐行对齐）；行号是一整块 `aria-hidden` 文本，编辑器的行号列另带一条始终为空的横向滚动槽，占位与文本框自己的滚动条一致，滚到底时行号仍与最后几行对齐；另含语言推断、文件大小格式化                                                                                                                                                                                                                                                                                |
| `WorkspaceTextNotices.tsx`  | 组件 | 文本上方的三类提示：只读原因（编码无法安全保存 / 混用换行方式 / 文件过大）、已恢复上次未保存的修改，以及保存冲突（另存为副本 / 放弃我的内容打开最新 / 用我的内容覆盖）；文案全部本地化，不透出服务端原文与技术术语                                                                                                                                                                                                      |
| `InlineWorkspaceDiff.tsx`   | 组件 | 工作区代码即时 Diff 对比抽屉/面板                                                                                                                                                                                                                                                                                                                                                                                       |
| `RichMediaFilePreview.tsx`  | 组件 | 富媒体（图片/音视频/PDF/Office/SVG）预览分发；`getPreviewKind` 扩展名路由 + `kind` prop 覆盖；图片禁用 artifact 编辑按钮                                                                                                                                                                                                                                                                                                |
| `useEscapeDismiss.ts`       | Hook | 临时浮层（右键菜单、对话框）的 Escape 关闭：监听 `document` 并终止事件，宿主（如工作台抽屉监听 `window`）不会随之一起关闭                                                                                                                                                                                                                                                                                               |
| `useWorkspaceFiles.ts`      | Hook | 三部署 agent vault 文件树：首扫两层，更深的文件夹经 `loadChildren` 按需加载，每次刷新都会重读已打开的文件夹，刷新期间原目录树原地保留、新结果到达时整体替换，换工作区则立即清空；register watch + SSE auto refresh（经 useGlobalEvents）；较旧的扫描结果与切换工作区后才到的文件夹结果一律丢弃                                                                                                                          |
| `useWorkspaceTextEditor.ts` | Hook | 单个文件的文本编辑状态：带版本读取、草稿与由草稿对照文件内容得出的 `dirty`；保存始终基于读取时的版本，文件在磁盘上已变化时保留草稿并进入冲突态（载入最新 / 覆盖 / 另存副本）；保存期间新输入的文字仍算未保存，同一文件同时只有一次写入；未保存草稿同步保留到 `useWorkspaceDraftStore`，下次打开接回（`restored`），文件已变则直接进冲突态；晚到的读取与保存结果不会作用到新文件，保存失败仍以本地化提示告知             |
| `__tests__/`                | 测试 | 组件与 Hook 的单元测试（jsdom）；`editorTestKit.ts` 是编辑器测试共用的读写桩与打开、输入助手，各测试文件仍各自声明 `vi.mock` |
