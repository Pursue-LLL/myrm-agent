# 真实官方外部链接对齐与实战商用检验套件架构设计 (_ARCH.md)

## 1. 业务背景与设计初衷
对标《谁最会做“给王总看的 PPT”？》中豆包工作建站实战（三只松鼠校招页去假数据化）：
- **行业痛点**：大模型生成落地页与 Web 应用时，往往充斥着 `href="#"`、`javascript:void(0)` 或 `https://example.com/apply` 等虚构假链接。这导致生成的应用只能作为“静态玩具（Demo）”，无法点击跳转到真实业务系统；
- **核心解决方案**：
  1. **实体识别与分类推断**：解析 HTML/JSX 中所有 `<a>` 标签与 CTA 按钮，根据锚文本关键词（如“投递/校招/加入我们”、“购买/下单/官方旗舰店”、“客服/咨询”）自动分类；
  2. **权威企业实体二级域名对齐**：对接权威企业实体映射库（如三只松鼠校招门户、天猫旗舰店、开发者平台），将占位假链自动对齐到真实有效的公网二级页面；
  3. **商用就绪度自检与代码重写**：度量整体真实对齐率（0-100%），支持一键批量对齐与源码自动安全回写，让生成网页 100% 具备工业级商用交付品质。

## 2. 状态机与处理流水线
```
           [ 网页/工件 HTML 源码输入 ]
                        │
                        ▼
           ┌─────────────────────────┐
           │   scanLinksFromHtml     │
           │   - 识别 href="#" 假链  │
           │   - 推断 CTA 业务意图   │
           └────────────┬────────────┘
                        │
                        ▼
        ┌───────────────────────────────┐
        │  useRealLinkAlignmentStore    │
        │  - 计算真实对齐率 (Rate %)    │
        │  - 匹配官方权威二级实体 URL   │
        └───────────────┬───────────────┘
                        │ 用户点击「一键批量对齐」
                        ▼
        ┌───────────────────────────────┐
        │     batchAlignPlaceholders    │
        │     - 假链状态变为 aligned    │
        │     - 对齐率跃升至 100%       │
        └───────────────┬───────────────┘
                        │ 用户点击「应用并替换到源码」
                        ▼
        ┌───────────────────────────────┐
        │     replaceLinksInHtml        │
        │     - 干净代码回写与商用交付  │
        └───────────────────────────────┘
```

## 3. 模块文件清单
- `realLinkTypes.ts`：外链实体模型（`DetectedLinkEntity`）、对齐状态与 Store 契约；
- `realLinkDetector.ts`：纯函数扫描、占位符判定、权威实体映射与 HTML 源码安全替换；
- `useRealLinkAlignmentStore.ts`：Zustand 集中式状态管理，协调扫描、批量对齐与代码重写；
- `RealLinkVerificationCard.tsx`：生产级商用就绪自检仪表盘，带健康度度量条与代码查看器；
- `index.ts`：统一模块导出。
