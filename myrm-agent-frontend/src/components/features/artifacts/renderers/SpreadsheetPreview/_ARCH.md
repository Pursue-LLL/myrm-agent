# SpreadsheetPreview/

CSV 解析与虚拟化 DataGrid 表格预览。

| 文件                              | 职责                                                                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `index.tsx`                       | 预览入口与布局                                                                                                                   |
| `CsvParser.ts`                    | CSV → 行列矩阵                                                                                                                   |
| `DataGrid.tsx`                    | 可滚动表格 UI                                                                                                                    |
| `columnWidths.ts`                 | 列宽：按表头与前 200 行内容量出每列宽度（中日韩宽字符按两倍计，夹在 72–320px），表头与每一行用同一组宽度，列才对得齐             |
| `SpreadsheetSelectionToolbar.tsx` | 选中一行后浮在表格底部的工具栏：把该行（含表头）设为聊天的限定目标，或复制为制表符分隔文本；按钮文案取自 `artifacts.spreadsheet` |
