# app/ (Next.js App Router)

## 架构概述

路由薄壳：布局在 `layout.tsx`，业务 UI 在 `@/components/features/*`。动态段 `[chatId]`、`settings/[tab]` 等仅做参数传递与鉴权包装。

## Service Worker（Web PWA）

| 文件    | 地位 | 职责                                                                                                                                                                                                                                                                           | I/O/P |
| ------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----- |
| `sw.ts` | 核心 | Web Push 专用 SW 源：`push` 显示通知、`notificationclick` 聚焦 / 导航 / 打开窗口（same-origin URL allowlist；已开 Tab 同 path 不同 query 时 `client.navigate`）；没有 `fetch` 监听；`install` 即 `skipWaiting`，`activate` 清掉本源全部 Cache Storage 条目后 `clients.claim()` | ✅    |

编译产物 `public/sw.js` 由 `bun run build:sw`（esbuild 打包 `sw.ts`）生成，不入库；注册见 `@/components/features/app-shell/service-worker-registrar.tsx`（生产 Web only；dev 注销 SW；Tauri skip）。

## 依赖

- `@/components/features/app-shell` — 全局初始化

## Locale 接力

营销站 `?locale=` 由根目录 `middleware.ts` 写 `NEXT_LOCALE` cookie（非 `app/` 路由内处理）。

## 约束

- 新页面优先复用 `features/` 组件，不在 `app/` 堆业务逻辑。
- 单文件 page >600 行应下沉到 `features/`（如 `batch-directories/` 两个 page 只做装配，实现在 `features/batch-directory/`）。
- `layout.tsx`：构建期静态 `metadata`（`lib/metadata/static-metadata.ts`）；`<body suppressHydrationWarning>` 压制浏览器扩展注入属性导致的 hydration warning；`LocalizedProviders` 仍在 Suspense 内（cookie locale）。
- `mermaid.css`（由 `globals.css` 引入）：Mermaid 图表 `MermaidChart`（`features/markdown-render-tools/`）的布局样式：`.mermaid-container` 取 `user-select: none`，`.mermaid-chart` 声明 `will-change: transform`（图表随缩放 / 平移变换），窄屏（≤768px）下容器上下外边距收紧为 0.75rem。配色与字体都由 `mermaid-theme.ts` 的 `buildMermaidConfig`（`themeVariables`、`fontFamily`）决定，本文件不设色值。
- `focus-ring.css`（由 `globals.css` 引入）：键盘焦点环基线，只作用于自身无 `focus`/`focus-visible` 样式的可交互元素（`@layer base`，任何 Tailwind utility 与组件样式都可覆盖；不匹配文本输入）；复用主题 token `--ring`，鼠标/触摸不触发。 组件若写 `outline-none` 就会覆盖它，须自带 `focus-visible:ring-*`，由 `scripts/check-a11y-ratchet.mjs`（`focus-visibility-scan.ts`）在 lint 阶段强制。
- `numbered-code.css`（由 `globals.css` 引入）：只读代码视图 `LineNumberedCode`（`features/workspace-browser/WorkspaceTextViews.tsx`）的行号样式，`@layer components`。行号是每个块级行 `::before` 上的 CSS 计数器，不在 DOM 文本里，所以不会被选中复制，替代文本 `/ ''` 让读屏跳过它；字号与行高（`--numbered-code-line-height`）由本文件设置，行高、行号与槽宽都由它派生，元素上不能再叠 `text-xs`/`leading-*`（utilities 层优先于 components 层，会把行高改掉、行号随之错位）。`.numbered-code-lazy`（组件在超过 2,000 行时才加）用 `content-visibility: auto` 跳过屏外行，以滚动条长度在行被看过前是估算值为代价换面板缩放时的布局开销；契约由 `src/app/__tests__/numbered-code-css.test.ts` 钉住。
- `workspace-code-editor.css`（由 `globals.css` 引入）：工作区代码编辑器 `WorkspaceCodeEditor`（`features/workspace-browser/`）的底色，让编辑区与行号槽取应用的 `--background`，两套主题下都与周围面板同色（不覆盖时深色主题下 Monaco 的 `#1e1e1e` 比面板亮一档，成了两块底色）。Monaco 的主题色是它注入的、不在任何 cascade layer 的样式写在 `.monaco-editor` 上的 `--vscode-*` 变量，`@layer` 里的覆盖规则无论选择器多具体都输给它，所以本文件刻意不放进 layer，也不写任何色值；代码本身的配色仍是 Monaco 主题的，与产品里其他 Monaco 编辑器一致。契约由 `src/app/__tests__/workspace-code-editor-css.test.ts` 钉住。
- `narrow-layout.css`（由 `globals.css` 引入）：窄屏兜底（`@media (max-width: 1023px)`）。布局是否进入移动形态要等客户端挂载后才判定，服务端与水合那一帧按宽屏渲染，所以这里去掉主内容区为侧栏留的左内边距（`.main-content-area`，边距来自内联 style，故用 `!important`），并隐藏宽屏专属的外壳（`.wide-layout-only`：导航栏、内容侧栏及其折叠按钮；抽屉里的形态不带这个类）。规则刻意不放进 layer：未分层样式天然高于 utilities，`display: none` 才压得住 `.fixed`、`.flex`。断点用 px 而不是 Tailwind 的 `lg`：`lg` 是 rem，媒体查询里的 rem 跟随浏览器默认字号，默认字号调大后会与 JS 判定错开，导航会整个消失。它与 `lib/utils/device/deviceDetection.ts` 的 1024 成对，由 `lib/utils/device/__tests__/deviceDetection.test.ts` 按宽度逐一比对。
- `base.css` 的 `@media (prefers-reduced-motion: reduce)` 通用选择器块：全局兜底，把全站 CSS 动画与过渡压到瞬时（`0.01ms` + `animation-iteration-count: 1`，`scroll-behavior: auto`），组件层不需要逐个处理。刻意不用 `animation: none`——瞬时收尾仍会派发 `animationend`，依赖它决定卸载时机的浮层才能照常收场；`none` 会让浮层判断不到动画而提前卸载。framer-motion 走 Web Animations API、CSS 覆盖不到，由 `PageLayout.tsx` 的 `<MotionConfig reducedMotion="user">` 负责（位置类动画瞬时、透明度淡出保留）。两个守卫分别由 `src/app/__tests__/reduced-motion-safety-net.test.ts` 与 `src/components/layout/__tests__/PageLayout.test.tsx` 钉住。
- `brand.css` 的品牌浮起按钮规则（`.btn-brand-elevation` 与 `button/a.bg-primary.text-primary-foreground|text-white`）：规则在 Tailwind layer 之外，优先级天然高于 `.fixed`、`.z-50` 等 utilities，所以写入 `position: relative` / `z-index` 的选择器都以零优先级的 `:where(:not([class*='fixed'], [class*='absolute'], [class*='sticky']))` 收尾，已自带定位的元素保留自己的定位与层级；否则悬浮按钮（实时桌面、桌面检查器展开态）会被拉回文档流、把空聊天页撑高。契约由 `src/app/__tests__/brand-elevation-positioning.test.ts` 钉住（对旧写法会失败）。

## 全局样式

`globals.css` 只做入口（由 `layout.tsx` 引入），自身不含规则：依次引入 `tailwindcss`、`@tailwindcss/typography` 插件与各分片。Tailwind 按引入顺序把分片内联成一份样式表，所以引入顺序就是层叠顺序（同优先级规则后者胜出），新分片放在它所依赖的规则之后。前五个分片（`mermaid.css`、`focus-ring.css`、`numbered-code.css`、`workspace-code-editor.css`、`narrow-layout.css`）见上文「约束」，其后的分片依次为：

| 文件                        | 地位 | 职责                                                                                                                                                                                                                                                | I/O/P |
| --------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| `tailwind-theme.css`        | 配置 | Tailwind v4 的 dark 变体、`@theme`（`--color-*`、`--radius-*`、`--animate-*`）与 PWA safe-area 内边距；新增语义色先在这里声明 `--color-<name>`，再到 `theme-variables.css` 的两套主题里取值（`verify:theme-colors` 据此判定语义色工具类是否已声明） | —     |
| `animations.css`            | 辅助 | 关键帧（`accordion-*`、`rotate-step`、`button-glow-breathe`、`button-float`、`enter` / `exit`）与替代 tailwindcss-animate 的 `animate-in` / `animate-out`、`fade-*`、`zoom-*`、`slide-*`、`duration-*` 工具类                                       | —     |
| `theme-variables.css`       | 核心 | `:root` / `.dark` 两套主题变量；Theme Engine 运行时令牌作用在外壳上的材质（`data-myrm-theme-art`）、双强调色主题下实心按钮的暖色强调（`data-myrm-theme-dual-accent`）与暗色下的强调面补丁                                                           | —     |
| `base.css`                  | 核心 | 全局基础：`* { border-color }`、`html, body` 的横向溢出限制与 `body` 底色 / 字体、等宽字体、可点击元素光标、`prefers-reduced-motion` 全局兜底、`.scrollbar-hide`、`.scroll-fade-x`、滚动条、typography 表格首列补丁                                 | —     |
| `component-styles.css`      | 辅助 | 组件级样式与动画：`progress-bar` 关键帧（Artifact 生成进度条，`ArtifactPortal` 以内联 `animation` 引用）、`.animate-shake`、`.animate-shimmer`、`.animate-node-pulse`（DAG 运行中节点的 box-shadow 脉冲，减少动态效果下关闭）                       | —     |
| `companion.css`             | 辅助 | 陪伴宠物的关键帧与 `.animate-companion-*`、`.animate-shimmer-overlay`                                                                                                                                                                               | —     |
| `mark-highlight.css`        | 辅助 | `<mark>` 高亮底色（亮色取主色 20%，暗色 30%）                                                                                                                                                                                                       | —     |
| `brand.css`                 | 辅助 | 品牌视觉：`.brand-gradient-*`、`.brand-elevation-slot`、浮起按钮 `.btn-brand-elevation`（含定位保护、悬停 / 按下 / 禁用与减少动态效果补丁）、`.brand-interactive-hover`、`.brand-selected-surface`                                                  | —     |
| `markdown-gfm.css`          | 辅助 | GFM 提示框（`> [!NOTE]` 等五类）与脚注                                                                                                                                                                                                              | —     |
| `dual-accent-selection.css` | 辅助 | 双强调色主题下的文字选区色                                                                                                                                                                                                                          | —     |
| `components-layer.css`      | 辅助 | Tailwind `components` 层：cmdk 命令面板（`.myrm-cmdk-*`，用 `@apply`）、安全区类（`.myrm-safe-*`）、`.shadow-brand`                                                                                                                                 | —     |
| `markdown-table.css`        | 辅助 | Markdown 表格的响应式外壳、工具条与窄屏样式                                                                                                                                                                                                         | —     |
| `backdrop-blur.css`         | 辅助 | 产品界面统一关闭 `backdrop-filter`                                                                                                                                                                                                                  | —     |

- 产品界面统一关闭 `backdrop-filter`（`backdrop-blur.css` 的 `[class*='backdrop-blur']` 覆盖）：同页多层模糊会显著抬高 GPU 占用，深色半透明底色已足够可读；新增玻璃质感请用更实的底色而不是模糊。
- `base.css` 的 `.scroll-fade-x`：不显示滚动条的横向滚动区的边缘渐隐。遮罩只在元素带 `data-fade-start` / `data-fade-end`（由 `hooks/ui/useScrollEdgeFade` 写入，表示该侧确有内容被裁）时才出现，且只渐隐被裁的那一侧 1.5rem；放得下时不加任何遮罩。两侧宽度变量都带 `0px` 默认值，只有一侧被裁时遮罩也完整。契约由 `src/app/__tests__/scroll-fade-css.test.ts` 钉住。
- 表面语义（`theme-variables.css`）：暗色 `--card` 由 `color-mix(background 94%, foreground 6%)` 派生、`--popover` 取 88%/12%，亮色两者取纯白；`--muted-foreground` 统一取 `foreground 60%`（暗色实测 7.08:1、亮色 5.22:1）。均由主题 token 派生，新增主题/art 组合无需逐个补色值；不要在组件里写死近黑/近白。
- 危险红有两个令牌（定义在 `theme-variables.css`，`tailwind-theme.css` 把 `--destructive-text` 声明成 Tailwind 颜色）：`--destructive` 是实心填充色（按钮底、着色底），作文字浅色只有 3.8:1、深色在弹层上只有 1.5:1；文字与线性图标用 `--destructive-text`（`text-destructive-text`，浅色 `#b91c1c`、深色 `#f87171`），在页面底、卡片、弹层、`popover/95`、`secondary` / `muted` / `accent` 与 `destructive/5` 到 `/20` 的着色底上都 ≥4.5:1（悬停升到 `/30` 时浅色 4.3:1）。文字不要加透明度修饰符（浅色页面底上 `/80` 4.6:1、`/70` 3.8:1，落在着色底上更低）；只有「悬停才变全色」的图标按钮可用 `/60`、`/70` 作静止态（图标要求 3:1，`/60` 为 3.1:1）。契约由 `src/app/__tests__/destructive-text-contrast.test.ts` 钉住（把填充色当文字、或浅色红过浅的写法会失败）；组件里写 `text-destructive`（填充色作文字）会被 `verify:theme-colors` 门禁零容忍拦下。

- 字体：`app/fonts.ts` 通过 `next/font/local` 自托管 `src/assets/fonts/InterVariable-latin.woff2`（OFL，400–600，47KB，预载）与 `AtkinsonVariable-latin.woff2`（OFL，400–700，33KB，按需）；`--font-sans`（`theme-variables.css`）以 `var(--font-inter, ui-sans-serif)` 开头，Atkinson 主题通过 `var(--font-atkinson)` 覆盖。构建、运行时与桌面打包都不依赖外网，CJK 按字形回退 PingFang/Noto。
