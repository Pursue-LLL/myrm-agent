# test-utils

前端测试共享层。断言守卫收敛各测试文件内的重复 if-throw 样板；真实翻译 mock 让测试能断言最终展示给用户的句子。

| 文件               | 地位 | 职责                                                                                        | I/O/P |
| ------------------ | ---- | ------------------------------------------------------------------------------------------- | ----- |
| `expectDefined.ts` | 核心 | 类型窄化断言守卫（undefined / null 两断言）                                                 | ✅    |
| `realIntl.ts`      | 核心 | 以真实语言包构造 next-intl mock（`vi.mock` 工厂内使用，译器按语言与命名空间缓存、引用稳定） | ✅    |
