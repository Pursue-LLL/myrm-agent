# hooks/voice/

全双工/PTT 语音会话：STT、TTS、OpenAI Realtime、Gemini Live、Agent WebSocket bridge。

## 文件清单

| 文件                     | 职责                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useVoiceSession.ts`     | 会话编排（barge-in、TTS queue 安全插入）；PTT context 与截图融合、传输状态同步、窗口事件桥与断句在 [`session/`](session/_ARCH.md)；会话是否在运行（`isActive`）交给 `useLiveMeetingNotes`，由它在会话结束时收尾纪要                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `useSpeechInput.ts`      | 多后端 STT 输入与主机就绪零延迟门禁（防盲录）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `useTTS.ts`              | TTS 输出门面（browser + API）：按 `mode` 取对应引擎，并统一提供 `toggle`（按状态朗读、暂停或继续）；同一引擎内同一时刻只有一个实例在朗读（浏览器靠整页朗读队列，API 靠模块级的「当前说话者」），两个引擎之间互不约束；引擎与共用类型在 [`tts/`](tts/_ARCH.md)；回归 `__tests__/useTTS.test.ts`                                                                                                                                                                                                                                                                                                                                                                                                     |
| `useVoiceAgentBridge.ts` | 服务端 Agent WebSocket bridge 与主机就绪连接守卫                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `useRealtimeVoice.ts`    | OpenAI Realtime WebRTC                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `useGeminiLiveVoice.ts`  | Gemini Live WebSocket                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `useLiveMeetingNotes.ts` | 会中实时纪要会话：final 转录入队上报（单飞循环排空 + 逐行 `line_id` 幂等，按智能体范围上报）+ 滚动结构化纪要快照；会议边界是会话 `active` 的升降沿：下降沿（停止、传输断开）与卸载都会先排空队列再 finalize 一次（单飞），把纪要发布进该智能体的知识库并清空看板，结果以 toast 告知（失败可重试，120 s 超时；服务端已不存在该会话的 404 只提示无法确认是否已保存，不重试；两条失败提示分别停留 8 s 与 15 s，长于 toast 默认的 4 s，因为保存结果只靠 toast 告知）；页面关闭时改发一次不等应答的 keepalive finalize（只发布服务端已收到的行，不排空队列、不弹 toast）；迟到的行丢弃，新会议的行等上一份纪要发布完再上报；回归 `__tests__/useLiveMeetingNotes*.test.ts`（共享底座 `liveNotesKit.ts`） |
| `useVoicePttListener.ts` | Tauri PTT → DOM CustomEvent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `voiceCommands.ts`       | 语音指令纯函数（停词精确匹配，句中口述不触发）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `voiceDeviceSettings.ts` | 语音设置（会话开关、全双工、Agent 桥接、模式）的设备端共用读写层：设置页写、聊天语音按钮读；浏览器拒绝存储时在本页内保留，本页写入与其他标签的改动都会通知读取方                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

## 依赖

- `@/store/*`、`@/services/*` — 配置与 API
- 消费者：`message-input-actions/`、`features/voice/`、`app-shell/voice-ptt-initializer.tsx`、设置页 `settings/sections/personal/VoiceSessionToggles.tsx` 与 `settings/sections/integration/channels/VoiceSessionModeSettings.tsx`（经 `voiceDeviceSettings`）

## 约束

- 域内相对 import（`./useTTS`）；域外 import 路径 `@/hooks/voice/<file>`
