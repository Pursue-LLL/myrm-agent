# agent/config-panel/

`useAgentConfigPanel.ts` 的逻辑切片：把弹窗保存配置的处理器从主 hook 拆出以控制行数。

| 文件               | 职责                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `handlers.ts` | 弹窗保存配置的处理器：会话已有配置就合并，还没有就在默认值上创建（弹窗保存的各项都保留）；保存时指令内容真的变了才置 `systemPromptEdited`（仅此时 `agent_config.system_prompt` 随请求发送），原样保存不算改写 |

主 hook 在同级 `../useAgentConfigPanel.ts`。
