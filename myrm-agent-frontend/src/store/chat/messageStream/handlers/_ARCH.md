# handlers/

## 架构概述

`AgentStreamEvent` 按事件域拆分的 SSE reducer 切片。由 `index.ts` 的 `STREAM_EVENT_HANDLERS` 顺序调用；共享依赖见 `handlerDeps.ts`。

## 约束

- 单切片建议 ≤300 行；新增事件优先扩展现有域文件或新增 `*Events.ts` 并注册到 `index.ts`。
- 可变回合状态只改 `ctx.added` / `ctx.recievedMessage`，禁止对解构常量赋值。
- message 状态只在 `actions.setMessages` 回调（draft）内读写：store 是 immer 不可变状态，`ctx.state.messages` 只是 stream 打开时的快照，本轮 assistant 消息只经 `setMessages` 进入 store，读快照永远找不到它，处理会静默落空；`ctx.state` 仅用于 `chatId` 与 `scheduler`；写入之后还要读最新 message（如 MESSAGE_END 触发后续建议）用 `../lastMessage.ts` 的 `readLastMessage`。新增或修改切片须用真实 store 的整轮流式测试覆盖（`messageStreamLiveStore.test.ts`）。
