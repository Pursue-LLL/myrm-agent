# chat/

## 架构概述

会话状态、SSE 流式 reducer、发送请求与类型契约。侧边栏 L1 内存 + L2 SessionStorage 双级 navigation snapshot + multi-pane `resolvePaneSnapshotBase`（含 per-chat `activeMoaPresetId`）实现 Fast UI Restore 0ms 视觉秒开恢复。
