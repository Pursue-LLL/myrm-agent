# tools/

## Overview
API layer of the browser toolkit. Maps BrowserSession capabilities to 8 LangChain @tool functions, each fenced behind the person's control of the browser (`user_control_gate.py`) and the cancel boundary.

## File & Submodule Index

| File | Role | Description | I/O/P |
|------|------|-------------|-------|
| __init__.py | Package | API layer of the browser toolkit. Maps BrowserSession capabilities to 8 LangChain @tool functions. | ✅ |
| _semantic_risk.py | Internal | Browser-layer semantic DOM risk classification — browser action preconditions (click/dblclick/check/uncheck mutations, key activation, implicit submit) and JS eval patterns layered on the shared cross-channel lexicon from `core.security.detection.semantic_risk` (SSOT shared with desktop AX gates). Consumed by semantic_dom_hitl.py. | ✅ |
| semantic_dom_hitl.py | Internal | Shared LangGraph HITL gate for session.interact, browser_interact_tool, and evaluate paths with key activation propagation; fail-closed when no graph context is available. | ✅ |
| cancel_boundary.py | Core | `apply_cancel_boundary`: wraps every tool coroutine in place. Before each action it heals a tab whose renderer crashed (`active_tab_crashed` → `recover_active_tab`), so the model does not hit a dead page on every call. A stopped run aborts the in-flight browser action within ~0.25s (`run_until_cancelled`), heals the tab (`recover_active_tab`) and returns `CANCELLED_RESULT` instead of an error. A run torn down without the token (executor timeout, stuck-task watchdog, shutdown) heals the tab too, then lets the cancellation continue. A call that fails because the Playwright driver exited heals the tab it died on too (the exit raises no crash report, so the failed call is the first sign) and the failure still reaches the model. A healed tab is blank, so the next text result is prefixed once with the session's reset notice (`take_tab_reset_notice`). A text result also ends, once, with what the downloads a page started came to after the action that started them was answered (`take_unannounced_downloads`), so a late download is never left unsaid; a structured result, an error or a cancelled result leaves it for the next answer. No-op outside an agent run (no cancellation token). Applied by both tool factories (`create_browser_tools`, `create_restricted_ax_browser_tools`), outside `user_control_gate.py`. | ✅ |
| user_control_gate.py | Core | `apply_browser_user_control_gate`: fences the browser tools behind the process-wide `UserControl` (`utils/runtime/user_control.py`). While a person drives the browser every tool waits except `browser_ask_human_tool` (the model hands the browser over with it, and a resumed run calls it again); past 600s the wait raises `UserTakeoverTimeoutError`. After the hand-over, `browser_interact_tool` / `browser_execute_script_tool` return `REOBSERVE_NOTICE` until `browser_snapshot_tool` has succeeded (the only call that hands back fresh refs); `browser_inspect_tool`, `browser_extract_tool`, `browser_navigate_tool` and `browser_manage_tool` only wait. Applied under the cancel boundary by both tool factories, so stopping a run also ends a waiting tool. A test pins the classified names to the tools the factories build. | ✅ |
| common.py | Core | Shared utilities for browser tools. `mark_untrusted`: unified output security boundary (credential redaction + untrusted-content wrapping) for every browser tool result. | ✅ |
| download_actions.py | Core | Agent-facing text of the download actions: `run_download_url` and `list_downloads_report` (the `download_url` and `list_downloads` actions of `browser_manage_tool`) and `describe_downloads_since` (the notes `browser_interact_tool` appends to a click that started downloads, and `browser_navigate_tool` answers a navigation to a file with), `late_downloads_notice` (what a later answer says of downloads that settled after their action was answered); `list_downloads` also hands over those notices, so the listing never leaves them to be said again. A download that is not kept is answered with its reason, never a bare failure; a file name and a reason can come from a hostile page, so every answer that carries one is wrapped via `mark_untrusted`. | ✅ |
| execute_script.py | Core | browser_execute_script_tool: Code-as-Action batch execution with AST privileged-API scanner + HITL gating. Output redacted + wrapped via mark_untrusted. The gate vets the call once, so the script runs pinned to the hand-over the model last observed (`planned_against`): when a person used the page meanwhile, its next session step raises `UserTakeoverDuringScriptError` and the output says the earlier steps already ran. | ✅ |
| extract.py | Core | browser_extract_tool: content extraction. | ✅ |
| inspect.py | Core | browser_inspect_tool: quick page structure analysis. Output redacted + wrapped via mark_untrusted. | ✅ |
| interact.py | Core | browser_interact_tool: element interactions with optional steps[] batch + NavPostActionGuard (cross-page hard navigation halt) + semantic DOM risk check (HITL for destructive/financial/admin actions). Supports coordinate mode (x/y parameters) for canvas/rich-editor pages. A click or double click that starts downloads, by element or by coordinates, is answered, once the downloads the page started have settled, with the files saved and the downloads refused (`describe_downloads_since`); it waits 50 ms for a download the click starts at once, so one a page starts later from a timer of its own is not in that answer and is told by the next answer of any tool (`cancel_boundary.py`) or by `list_downloads`. Output redacted + wrapped via mark_untrusted. | ✅ |
| manage.py | Core | browser_manage_tool: session management + domain skill execution (run_site_tool/list_site_tools). Actions include runtime mobile device emulation (`emulate`, via DeviceEmulator). HITL via browser_ask_human_tool; no wait_for_user. `download_url` and `list_downloads` delegate to `download_actions.py`. All page-sourced outputs (evaluate/console/network/domain skill/downloads) redacted + wrapped via mark_untrusted. | ✅ |
| navigate.py | Core | browser_navigate_tool: URL navigation; Dynamic Hints for web_search/web_fetch when mounted; success path appends ≤20 compact interactive refs. An address that answers with a file makes Chromium turn the navigation into a download and fail it although the file is saved; when the navigation failed and a download started during it, the answer says so and carries what the download came to (the file, or why it was not kept), so the agent neither retries nor reads a failure. Output redacted + wrapped via mark_untrusted. | ✅ |
| snapshot.py | Core | browser_snapshot_tool: ARIA tree capture. Auto-detects canvas/rich-editor visual content and appends [VISUAL_CONTENT_DETECTED] hint to guide agents toward coordinate mode. | ✅ |
| takeover.py | Core | browser_ask_human_tool: Agent-triggered human takeover via LangGraph interrupt; SSE includes runtime `is_managed` (managed→VNC, external/CDP→in-chat banner). Result (post URL / page title / user message) redacted + wrapped via mark_untrusted. | ✅ |
