# fetchers/

## Overview
Toolkits Web_Fetch Fetchers module.

## File & Submodule Index

| File | Role | Description | I/O/P |
|------|------|-------------|-------|
| __init__.py | Package |   Init   | — |
| bounded_get.py | Core | `bounded_get` — one GET through Scrapling whose body is held to `MAX_TRANSFER_BYTES` (the binary router's `MAX_BINARY_SIZE`, 20 MB) while it is received. Scrapling buffers and parses a whole response before any size check can run, so a compressed body that decodes to gigabytes, or a slow giant page, would cost memory and event-loop time in proportion to what the server sends. libcurl hands each decoded chunk to a sink that keeps the first `MAX_TRANSFER_BYTES + 1` bytes (the extra byte tells a file over the limit from one exactly at it) and ends the transfer by returning `CURL_WRITEFUNC_ERROR`; status and headers then come from the write error, which carries the response received so far. The request is attempted once; any other failure is raised. Returns `FetchedResponse`. curl_cffi and Scrapling are imported when a request is made, so importing the engine needs neither. | ✅ |
| browser_fetcher.py | Core | Provides BrowserFetcher. A navigation the SSRF policy blocks raises `SSRFSecurityError` (never degrades to another tier); each fetch gets its own explicit-origin grants because pooled CRAWL contexts outlive it. | ✅ |
| http_fetcher.py | Core | L1 HTTP fetcher (Scrapling curl_cffi). HTTP/2 default; HTTP/3 retry on 403/antibot/empty only; skipped with proxy pool. SSRF defense through `FetchTargetGuard` on every hop (the requested URL and each redirect `Location`): a hop is judged and requested in its canonical spelling (`canonical_url`), so libcurl connects to the host the policy classified. Under the cloud policy the request is pinned to the resolved address, and when it fails (an HTTPS certificate names the host, not the address) it is retried by the canonical name, which resolves again; a rejected hop raises `SSRFSecurityError` instead of returning None, so the engine does not retry the same URL on a browser tier. Every body is received through `bounded_get` (no response holds more than `MAX_TRANSFER_BYTES + 1` bytes) and classified once by `utils.content_sniff.classify_payload` (declared type plus leading bytes): web pages and text are decoded into `html` and tagged `kind` WEB or TEXT, and only those bodies are cut at a ceiling: `MAX_HTML_BODY_BYTES` for a web page (its Markdown conversion is the costly step) and `MAX_PLAIN_TEXT_BODY_BYTES` for text (it follows what a stored copy of a page can hold). A cut body is decoded as `partial` (half a character at the cut is dropped instead of spoiling the charset choice) and the result carries `source_truncated`. A file stays whole as `raw_body` (`kind` BINARY) because a truncated PDF or Office file cannot be parsed; the transfer bound is the binary router's size limit, so a file over it arrives one byte over and the router drops it. The HTTP/3 retry lane only retries web pages. | ✅ |
| target_guard.py | Core | `FetchTargetGuard` — per-fetch SSRF policy shared by the HTTP and stealth tiers. `canonical_url` is the spelling a hop is judged and dialed in (`utils/url_syntax.py`; a URL with none is refused with `SSRFSecurityError`); `pin` judges it and returns the URL to request. Cloud policy: DNS-resolved, every address public. Local policy (`allow_private_networks`): the URL is judged, granted and resolved in canonical spelling (`pin` returns the URL as given) through `RedirectHopEvaluator.evaluate_hop_resolved` (a hostname resolving to loopback, link-local or metadata is judged as that address), the requested origin may be private, any other private origin reached by redirect may not, cloud metadata never may; skill DLP allowlist and `MYRM_ALLOWED_INTERNAL_HOSTS` apply under both. | ✅ |
| protocols.py | Core | Provides FetcherType, FetchResult (with `kind: PayloadKind`, WEB by default and BINARY whenever `raw_body` is set, and `source_truncated` when the fetcher cut the body at its size ceiling), Fetcher protocol. | ✅ |
| stealth_fetcher.py | Core | Stealth Fetcher — Maximum anti-detection based on Scrapling Patchright + BrowserForge. DNS leak prevention via DoH when proxy is active. Ad/tracker domain blocking via Scrapling `block_ads`. Scrapling navigates without a route hook, so the requested URL is judged before the browser starts and the page it ended on before the body is returned (`SSRFSecurityError` otherwise); the hop between them cannot be vetted in flight. | ✅ |
