# cli/

## Overview
CLI runtime backend — spawns one external CLI agent process per turn (Claude Code, Codex, ...) and streams its NDJSON output as `RuntimeEvent`s. Conversations continue through the CLI's own session id: it is stored the moment the CLI announces it (Claude `system/init`, Codex `thread.started`) and replayed with the CLI's resume syntax.

## File & Submodule Index

| File | Role | Description | I/O/P |
|------|------|-------------|-------|
| __init__.py | Package | Facade: lazy `CliRuntime`. The other modules are imported by their own path. | ✅ |
| dialect.py | Core | Per-CLI command-line differences (`CliDialect`): resume syntax (Claude `--resume <id>`, Codex `exec resume <id>`), native turn limit (Claude `--max-turns`), partial-message streaming, default environment (`env_defaults`: Claude `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`, so a headless turn leaves no background task that keeps `claude -p` alive); session-id shape check (`is_session_id`). A CLI without a dialect is spawned as configured. | ✅ |
| failure.py | Core | `classify_failure`: the `AcpError` of a finished attempt from the CLI's own words (Claude `result` line plus the `assistant` line's `authentication_failed` category: max turns / auth / rate limit; else exit code → crash carrying the CLI's last `error` notice or its stderr tail); a process this runtime stopped is a cancellation, never a crash. | ✅ |
| parser.py | Internal | Event builders shared by the output formats (tool call / result with one-line summary and bounded output, usage, `turn.failed` → ERROR event (auth only for `unexpected status 401`), thinking, Codex `item.*` events) and `error_message`, the text of an `error` line whatever shape it has. | ✅ |
| process.py | Core | `CliProcess` / `spawn_cli_process`: one CLI process group — line-wise stdout (16 MiB line limit), bounded stderr tail, and the only code that stops it (idempotent SIGTERM→SIGKILL, shielded from caller cancellation, runs on every exit path of the context). `lines(idle_tick)` also yields `None` after each silent period, cancellation-safe (a partly read line stays buffered). `wait()` takes the exit code from the transport (asyncio's `Process.wait()` resolves only after every pipe closed, which a grandchild holding stderr delays) and bounds the stderr drain. A program that does not exist raises `CliLaunchError`. | ✅ |
| runtime.py | Core | `CliRuntime`: launches a turn, resumes the announced session (only from the directory that created it), retries a rejected resume once as a fresh session in the same turn, persists the announced id at once, applies a stop that lands before the process exists, says `working` (elapsed time) every 15 s of CLI silence so a host's idle watchdog does not mistake a long quiet turn for a hung one, reports a missing program once as `BACKEND_NOT_FOUND`, and ends the turn with DONE or the one classified ERROR. | ✅ |
| session.py | Core | `CliSessionBook`: bounded memory-first CLI session records with best-effort write-through to the host `CliSessionStore` (contract and `CliSessionRecord` live in `types.py`); store failures degrade to a fresh session and never fail a turn. | ✅ |
| turn_parser.py | Core | `TurnParser`: stateful per-turn NDJSON parser (Claude content blocks / `stream_event` text deltas deduplicated against the full message, Codex `item.*`, plain text) exposing the announced session id, the CLI's own `result` verdict and the last top-level `error` / `stream_error` text as `notice` (Codex prints one per request retry, so it is not a failure by itself). | ✅ |
