# tests/support/

## Overview

Pytest-only helpers, not shipped in the harness wheel: process teardown and marked-process control, a memory- and time-guarded child process and read observation, real-git and live-MCP-server fixtures, loopback HTTPS and `CONNECT`-proxy peers with a clean TLS slate and probes of what a context trusts, damaged, old-tokenizer and out-of-space FTS5 indexes, completion-guard drivers with call-record and run-context builders, skill-metadata builders, synthetic package trees for the module-reachability tests, a model-request stand-in and a memory-manager binding for the memory-context middleware, store doubles, host spellings and a Host-header listener that show which host a client dials, credential-shaped fakes whose provider prefix is joined at call time, and the autouse plugin that empties the per-run guard registries around every test. The `test_*.py` files here test those helpers.
