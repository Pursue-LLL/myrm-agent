# tests/support/

## Overview

Pytest-only helpers, not shipped in the harness wheel: process teardown and marked-process control, a memory- and time-guarded child process and read observation, real-git and live-MCP-server fixtures, loopback HTTPS and `CONNECT`-proxy peers with a clean TLS slate, a forwarding-proxy double that records the address a client sent through it and probes of what a context trusts, damaged, old-tokenizer and out-of-space FTS5 indexes, completion-guard drivers with call-record and run-context builders, an Anthropic Messages double that refuses what the real API refuses, the signed tool loop that runs the shipped stack against it and a clock a test moves forward to reproduce an idle gap, skill-metadata builders, synthetic package trees for the module-reachability tests, a model-request stand-in and a memory-manager binding for the memory-context middleware, an idle-task driver that returns the events one task publishes, store doubles, host spellings and a Host-header listener that show which host a client dials, credential-shaped fakes whose provider prefix is joined at call time, and the autouse plugins that empty the per-run guard registries and the memory deleted-chat fence around every test. The `test_*.py` files here test those helpers.
