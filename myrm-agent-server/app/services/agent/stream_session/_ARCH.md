# stream_session 模块架构

General Agent SSE 流式会话的服务层实现。HTTP 路由装饰器保留在 `app/api/agents/general_agent/streaming.py`。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `orchestrator.py` | 核心 | 流式会话主编排：校验（含 **HITL pending approval gate**：非 resume 新 run 且有 `count_pending_for_chat`>0 时返回 `agent_busy_streaming_response`）→ **`try_reserve` → E1 early `StreamingResponse`**（`orchestrator_turn_launch.launch_early_buffered_stream`）；busy → `agent_busy_streaming_response`；`finally` release 预占 | ✅ |
| `orchestrator_turn_launch.py` | 核心 | E1 受理阶段（`launch_early_buffered_stream`）：把 `_background_turn` 作为独立 task 启动并立即答复客户端；`_background_turn` 入口绑定 harness `session_lock.set_current_chat_id(request.chat_id)`（否则 SnapshotObserver 快照以 `"default"` 落盘，revert API 按真实 chat_id 查询永远为空）与 `set_current_agent_id`，turn 抛错 → `fail_buffered_turn`，finally `reset` + 调 `gateway.release_if_reserved_only(chat_id)` 清理未接管预占；随后 `session_reservation.transfer_to_stream()`；multiplexed → JSON accepted，否则 SSE `StreamingResponse` | ✅ |
| `orchestrator_turn_body.py` | 核心 | E1 后台 turn 本体（`execute_agent_turn_after_reserve`）：**回合入口（首个 await 之前）同步登记 `CancellationToken`**，setup 期间到达的 Stop 即可命中本回合（setup 阶段失败由 `fail_buffered_turn` 注销令牌、向 buffer 写 error SSE 并关闭 buffer；正常结束由 stream finalize 注销）→ **先提交 user row** → `run_pre_reply_compact_with_sse` → load history → prewarm → **`pump_to_buffer`**；非 resume 回合在 `convert_to_general_agent_params` 之后调 `remember_turn_routing` 记录该回合的路由结果，供 HITL resume 沿用同一模型；`write_interrupted_turn_marker` 写预写式中断标记（记录用户行实际落库 id，崩溃续跑据此排除该行）| ✅ |
| `pre_reply_compact_sse.py` | 核心 | Web pre-reply idle compact SSE 生命周期（active → gate → completed/failure；gate exception → failure SSE；复用 frontend `context_compaction` progress steps） | ✅ |
| `stream_session_types.py` | 核心 | `AgentStreamSession` 数据类与断连宽限常量；承载流式会话起点时钟与端到端 TTFT 采样值（`stream_started_at_monotonic` / `stream_ttft_ms`）及智能路由归因（`routing_reason`）；`pre_reply_compact_result` + `pre_reply_compact_sse_sent` 供 pump 去重 SSE | ✅ |
| `stream_disconnect.py` | 核心 | 直连 SSE 回合的断连宽限：`build_disconnect_checker`（客户端断连且无订阅者 → 计时，超过 `GRACE_PERIOD_SECONDS` 才取消；long-running 回合从不因断连取消）与 `watch_client_disconnect`（异步上下文管理器，单一作用域持有 `CancellationMonitor`：multiplexed 回合与 HTTP 请求解耦、不建 monitor；直连回合进入时 start、退出时 stop，退出先于 finalize） | ✅ |
| `lazy_session_gate.py` | 核心 | 延迟持久化门禁协议：推迟全新会话的数据库记录与沙箱目录物理创建，直至收到首个 active generation chunk（token/reasoning/tool_call）；提供 `PendingSessionDraft` 与幂等提交屏障 `commit_lazy_session_barrier`；提交用户行时 `mark_read=True`（新会话的在场盖章必须在此落库，建会话前不存在可盖章的行） | ✅ |
| `memory_brief.py` | 核心 | 发送后首 token 前的记忆简报预计算（同源 snapshot + 预览 payload） | ✅ |
| `_memory_status_helpers.py` | 辅助 | Memory brief 状态组装 SSOT：统一构建 `memory_brief_status`（`ready/skipped` + `source(preflight/runtime_fallback)` + `injection`）供 `stream_loop` 与 `stream_finalize` 复用；可选 `session_ephemeral_delta_count`（同 chat 活跃覆盖条数，仅 GUI 元数据）；injection 校验复用 harness 公共契约；内置 Prometheus 观测与 unknown 枚举告警 | ✅ |
| `stream_chunks.py` | 核心 | SSE 预检编排（凭据、Vision fallback、**config gap / migration readiness gap / entitlement gap 三轨**；**turn prewarm** 等待态 STATUS `turn_prewarm_agent` / `turn_prewarm_memory`；`routing_decision` 事件下发 tier、specialty 与 `routing_reason` 归因）+ `generate_cancellable_stream` 生成器主体;流在 failover emitter 与 `watch_client_disconnect` 同一作用域内运行（monitor 随作用域退出而 stop，先于 finalize）;`BaseException` 兜底捕获 → `yield_stream_exception_chunks`,`finally` 调 `finalize_agent_stream_session` | ✅ |
| `stream_loop.py` | 核心 | Agent 主流 SSE 循环;路由 Fast Lane / Wiki Knowledge Lane / Dynamic Workflow (含 auto-escalate 与 Admission Fast-Path 绕行) / GeneralAgent;首 token 前发射 `memory_brief` 预览;`message_end` 注入 `stream_ttft_ms`、`turn_prewarm_hit` / `turn_prewarm_ms` 与 memory brief 遥测;检测 `clarification_required` / `directory_request_required` 挂起表单超时;拦截 `MissingSemanticsBlockedError` 并发射结构化 `missing_semantics_blocked` SSE 与安全审计落库 | ✅ |
| `workflow_escalation.py` | 辅助 | 纯规则 DW Engine 建议与准入门禁检测器：多目标/可拆分结构识别与 Admission Check（0 LLM 调用） | ✅ |
| `stream_finalize.py` | 核心 | 流错误处理与会话 teardown；`ConfigIncompleteError`（含 OpenAPI Turn1 加载失败 `openapi_load_failed` / 预算 `openapi_direct_budget_exceeded`）→ 用户可见 SSE error + resolution_steps；`AgentQueueTimeout` → 结构化 SSE 错误（`error_kind=concurrency_limit` + `diagnostic_result`：按 `reason` 三态区分 memory_pressure/user_limit/global_limit、命名 `active_sessions` 占用者（截断至 3 个 + `+N more`）、i18n 用户文案与 resolution_steps）；回合正常结束后清除 `InterruptedTurnMarker`（crash auto-continue write-ahead marker）；致命异常（MyrmLLMError/AgentExecutionTimeout/Resume fail/通用 Exception）设置 `session.had_fatal_error`；`asyncio.CancelledError` 分支调 `kill_session_jobs(chat_id)` 覆盖 SSE 硬断；当请求携带 `turn_capability_telemetry` 时，异常分支与 finalize 终态会写入 server authoritative `send_failed/send_completed`（HITL pending 不提前落终态，避免误判）；非 pending HITL 时在 `RunDigestStore.end_run` 后发布 `session_completed`/`session_failed` AppEvent 供出站 Webhook；持久化阶段总是尝试读取 harness memory telemetry 并写入 `memoryBriefSnapshotId`/`memoryBriefStatus`（含 `injection` 语义），并持久化端到端 TTFT（`streamTtftMs`）；当缺少预检状态但 runtime injection 存在时持久化 `skipped + source=runtime_fallback + injection`，`memoryBudget` 保持独立于 citations 持久化；persist 前调用 `merge_memory_citation_fallback` 回填 `citedMemoryIds`；citations 去重保持首见顺序确保首屏与刷新后展示一致；归一化后的 `memoryBriefStatus` 额外以 `phase=persist` 进入 server→control-plane 聚合遥测队列（批量上报）；若请求携带 migration readiness anchor，则在 finalize 记录首轮执行结果（success/failed/no_output）回写导入账本用于 readiness↔首轮成功率对账；finalize 末尾在 profile `skill_manage` ON 时把未满窗的残余轨迹切片入队进化队列；GA LangGraph resume 成功或 DR `status clarify/resolved` 后倒序扫描 assistant 行，将最新未答 `extra_data.clarification.answered=true` 写回 DB（倒序扫描定位宿主行，不用 API message_id）；pending clarification 或 collector `clarification.answered=false` 时注册 900s no_answer auto-resume；pending directoryRequest 时注册 900s deny-grant auto-resume（优先级 clarify > directory > approval 300s） | ✅ |
| `turn_capability_terminal.py` | 辅助 | 单轮 Skill/MCP 覆写终态锚点：消费 `AgentRequest.turn_capability_telemetry`，服务端落库 `send_completed/send_failed`，并把流异常归一化到 `failure_reason` 枚举 | ✅ |
| `migration_readiness_anchor.py` | 辅助 | 迁移 readiness 双锚记录助手：消费 `migration_readiness_anchor`（import_batch_id），按 stream finalize 信号归类首轮结果（success/failed/no_output）；preflight 未写入 live 状态时 finalize 再 live-resolve 一次，永不用 anchor 快照作 truth；函数内 lazy import `get_session_factory`（与 conftest patch 一致） | ✅ |
| `migration_bound_project.py` | 辅助 | 迁移 vault bind 同窗 handoff：persist 后、convert 前消费 `migration_bound_project_id`，`move_chat_to_project` 写 SSOT；chat 已有 project_id 或 resume 时跳过 | ✅ |
| `migration_readiness_preflight.py` | 辅助 | 迁移 readiness 软门禁：anchor 携带 batch_id 时 live-resolve readiness，在 stream 早期对 warning/critical 发射 issue-aware `capability_gap`（含 settings_path）；生产仅 async `resolve_and_build_*`；函数内 lazy import `get_session_factory`；不阻断执行、不改 Turn1 工具绑定 | ✅ |
| `stream_pump.py` | 核心 | 将 chunk 泵入 `GlobalStreamRegistry` buffer；orchestrator 未发送时补发 pre-reply compact SSE；`pump_to_buffer` 供 E1 后台 turn；long-running 回合在客户端断连后正常/失败结束时发 `source=offline_guardian` 的 SystemNotification；共享 project 并发：经 `_acquire_guarded`（分片轮询 `cancel_token`，取消可中断）获取 project turn lock，排队期间发 `waiting_for_turn`、获取后发 `waiting_for_turn_clear`；`lock_acquired` 标志保证 `finally` 仅释放当前请求真正持有的锁（取消等待不误释放他人锁）；`finally` 调 `gateway.release_if_reserved_only(chat_id)` 释放未被 `execute_stream` 接管的预占 session（锁等待期间取消不会让 chat 永久 busy） | ✅ |
| `session_reservation.py` | 辅助 | `ChatSessionReservation`：orchestrator persist 前 gateway 预占/early exit release/transfer 至 execute_stream | ✅ |
| `stream_busy.py` | 辅助 | `agent_busy_streaming_response`：HTTP 200 + SSE `{type:error, error_type:AgentBusyError, status_code:409}` SSOT | ✅ |
| `stream_lane_factory.py` | 核心 | Dynamic Workflow / Deep Research / Fast Lane SSE 工厂；DR 完成回调经 `resolve_wiki_vault_path(agent_id)` 写 raw + 编译入队 | ✅ |
| `moa_overlay_setup.py` | 辅助 | Agent-loop MoA overlay：解析 `engineParams.moa_overlay` reference 模型并构建 harness middleware；支持 `user_turn`、`per_iteration`、`every_n` 以及自适应 `risk_triggered` 模式并透传自适应风险门禁参数；支持在 `privacy_filter != "off"` 时自动注入 `leak_detector.redact_leaks` 完成参考参谋上下文深度凭证脱敏；无可用 ref 时返回 None + `resolve_moa_overlay_skip_reason` 供 stream 发 `moa_overlay_skipped` SSE；skip reason 含 `budget_pressure`、`insufficient_refs`、`risk_trigger_timeout`（runtime 由 harness middleware emit） | ✅ |
| `lanes/` | 核心 | Chat 专用 lane 流（见 [lanes/_ARCH.md](lanes/_ARCH.md)） | ✅ |
| `reconnect.py` | 辅助 | Last-Event-ID SSE 重连 | ✅ |
| `risk_gate.py` | 辅助 | 流式输入 risk 拦截：检测与位置记录取自共用入口 `services/risk/ingress.screen_user_text`，命中时推送只含规则列表（id、名称、严重度）的 `risk_blocked` SSE，提示文案由前端按用户语言生成；编排器在 ContextGuard 大文本溢出落盘之前调用它，超长粘贴里的密钥因此不会先落盘 | ✅ |
| `entitlement_gap_preflight.py` | 辅助 | Stream 早期 factual gap SSE（不改 Turn1 工具绑定）：web_search profile ON 但 runtime 不可用 → `reason=not_configured|unreachable` + `settings_path=/settings/search`；substring enable-and-resend entitlement toasts removed | ✅ |

## 依赖关系

- `app/services/agent/params/` — 请求参数转换
- `app/services/agent/execution_cache/prewarm/` — turn1 冷启动预热（EmptyChat focus + send join）
- `app/services/agent/memory_brief_telemetry/` — sandbox Control Plane memory brief 状态批量遥测（`stream_loop` / `stream_finalize` enqueue；用户可见 SSE 契约见 `_memory_status_helpers.py`）
- `app/services/agent/streaming_support/` — SSE 辅助与内容收集
- `app/services/agent/streaming.py` — Harness 流式桥接
- `app/services/wiki/vault` — Deep Research vault 与 API 共用 wiki 路径与 archiver
- `myrm_agent_harness.agent.streaming.stream_buffer` — 全局流 buffer
