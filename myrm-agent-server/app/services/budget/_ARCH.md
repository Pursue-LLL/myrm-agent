# Budget Services Architecture

## 架构概述

服务端预算层：加载并持久化用户预算策略，向 Agent 工厂注入多维预算守卫，按渠道隔离配额，并桥接 harness 的四档渐进花费干预引擎。

## 文件清单

| 文件 | 地位 | 职责 |
| --- | --- | --- |
| `__init__.py` | 入口 | 包标识，不导出符号 |
| `enforcer.py` | 核心 | 预算策略读写、进程级多维预算守卫单例、执行阻断判定与会话预算重置 |
| `channel_budget.py` | 核心 | 渠道级日预算策略、守卫注册表与成本记账，避免单个渠道耗尽全局预算 |
| `spend_control_service.py` | 桥接 | 提供四档渐进花费干预引擎的进程级单例 |
