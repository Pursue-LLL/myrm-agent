# services/code_graph 模块架构

## 架构概述

代码图谱静态分析与符号抽取服务。基于 AST 解析代码仓库符号、调用链与继承关系，提供 SQLite WAL 持久化图存储与查询编排。

## 目录文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `__init__.py` | 模块入口 | 暴露代码图谱服务与数据模型接口 | ✅ |
| `models.py` | 领域模型 | 代码图谱领域数据结构定义（SymbolNode, CallEdge, CallSite 等） | ✅ |
| `ast_extractor.py` | 核心服务 | 基于 AST 的多语言符号、调用关系与依赖抽取器 | ✅ |
| `graph_store.py` | 持久化存储 | 基于 SQLite WAL 模式的代码图谱拓扑与元数据存储引擎 | ✅ |
| `service.py` | 业务编排 | 代码图谱构建、增量更新与拓扑检索服务 | ✅ |
| `cli.py` | 命令行工具 | 代码图谱离线索引构建与验证 CLI | ✅ |
