# services/observability 模块架构

## 架构概述

运行时全要素可观测性与资源计量服务层。负责跨会话的搜索引擎调用配额跟踪、429 智能自愈与浏览器沙箱计算时长/网络传输数据流遥测记录。
与数据库持久化模型 `runtime_quota_metric.py` 协同，为前端用量仪表盘与统计中心 API (`/api/v1/statistics/quota-runtime`) 提供高内聚的业务服务逻辑。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `runtime_meter_service.py` | 核心 | 提供搜索额度账本记账、多供应商月度配额跟踪、429 熔断与浏览器运行时长/流量遥测聚合服务 | ✅ |
