
# app/services/repair 模块架构

运行时修复服务。提供白名单化的修复动作，响应健康检查发现的问题（浏览器孤儿进程清理、SQLite 备份/恢复等），所有修复需经用户确认后执行。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `models.py` | 基础 | 修复动作数据契约、枚举与请求响应模型定义 | ✅ |
| `sqlite_repair.py` | 实现 | SQLite 热备份与自愈还原执行逻辑 | ✅ |
| `actions.py` | 核心 | 白名单修复动作编排、发现推荐与执行路由分发 | ✅ |
