# services/system/

## 架构概述

系统运维与技术支持服务模块。负责聚合系统环境元数据、Doctor 健康检查快照、脱敏 Agent Profile 配置与近期待排障日志/事件，提供一键脱敏支持排障包（Support Debug Bundle）生成能力。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `__init__.py` | 包入口 | 模块导出与初始化 | ✅ |
| `support_bundle_service.py` | 核心 | 结构化系统诊断信息聚合与内存 ZIP 归档生成（带双重脱敏、超时保护与体积熔断） | ✅ |
