# services/weekly_report 模块架构

## 架构概述

周报生成 SOP 与知识库（Wiki）沉淀服务层。提供基于多角色模式（研发、产品、管理、通用）的执行轨迹周报合成算法，以及周报一键转化为 Wiki 结构化知识条目的提取与幂等持久化服务。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `models.py` | 核心模型 | 定义周报角色模式、轨迹条目、章节结构与 Wiki 知识转化载荷模型 | ✅ |
| `weekly_report_service.py` | 核心服务 | 提供多角色自适应周报模板渲染、证据引用整理与 Wiki 知识入库服务 | ✅ |
| `trajectory_aggregator.py` | 聚合工具 | 提供针对周报时间窗口与角色维度的轨迹筛选与数据整理适配层 | ✅ |
