# services/memory/dreaming 模块架构

## 架构概述

扎根式做梦与认知日记业务服务层。编排底层 Grounded Dreaming 跨会话空闲知识聚类与蒸馏引擎，提供梦境日记持久化与多维过滤查询、用户审查反馈状态流转（采纳/废弃/纠偏），以及外科手术式会话记忆精准拔除业务接口。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `service.py` | 核心 | 梦境日记业务编排与持久化服务。管理认知洞察记录、用户审核反馈，以及调用底层算子执行会话级派生记忆外科手术式拔除 | ✅ |
