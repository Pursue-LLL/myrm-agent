# services/memory/ltra 模块架构

随身感知“听—译—记—办”业务服务层。编排底层多说话人录音转写事实蒸馏、原声时间戳切片防篡改锚点、自然语言原话精准追问、HTTP 206 毫秒级音频切片流式代理，以及一键派发至沙箱数字员工执行闭环。
