# services/machines 模块架构

## 架构概述

自托管机群全局监控看板与远程人机同屏接管服务包。对标 Cursor Dashboard "My Machines" 与 Live Takeover 交互体系，管理接入的物理机与云端容器节点，实时采集 CPU/内存/磁盘/活跃任务遥测指标，并提供远程人机同屏接管会话状态机，解决反爬与死锁场景下的人机无缝协同痛点。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `machine_types.py` | 核心 | 机群节点、遥测指标、平台枚举、注册令牌与接管会话 Pydantic 契约 | ✅ |
| `machine_service.py` | 核心 | 单例服务：机群注册表管理、一键快速注册命令生成、心跳更新与接管状态机调度 | ✅ |
| `__init__.py` | 门面 | 导出公共类型与单例服务 | ✅ |

## 设计原则

- **极简接入**：一键生成带鉴权 Token 的单行快速注册命令，3 秒内完成握手。
- **状态透明**：实时遥测追踪 CPU/内存/磁盘占用与活跃任务数，杜绝远端智能体运行状态黑盒。
- **人机无缝接管**：支持在反爬与验证码场景下原子切换控制权（Agent ⇄ Human Takeover）。
