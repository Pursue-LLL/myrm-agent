# services/cron_digest 模块架构

## 架构概述

自然语言驱动的群聊消息实体聚类与时间轴定时研报自动化流水线服务层。负责将非结构化的自然语言指令解析为标准 Cron 定时任务，并从群聊历史消息流中提取实体事实，生成结构化时间轴研报。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `models.py` | 核心模型 | 定义自然语言 Cron 编译意图、实体事实、聚类分组与时间轴研报数据结构 | ✅ |
| `compiler.py` | 核心服务 | 解析自然语言提示词中的时间周期、目标渠道与研报主题，输出标准 Cron 意图 | ✅ |
| `clusterer.py` | 核心服务 | 过滤低信噪比灌水闲聊，按实体聚类事实并构建时间轴研报 Markdown | ✅ |
