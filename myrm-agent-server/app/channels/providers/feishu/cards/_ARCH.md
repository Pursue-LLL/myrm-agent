# feishu/cards/

## 架构概述

飞书卡片构造：通用卡片、动作、文本与特殊卡片分层，`__init__.py` 保持原 `cards` 导入面。上级：[../_ARCH.md](../_ARCH.md)。

## 文件清单

| 文件 | 职责 |
|------|------|
| `__init__.py` | 聚合导出全部卡片函数 |
| `builders.py` | 组件/思考/结果卡片与成本备注 |
| `actions.py` | 卡片动作按钮构造与回调解析 |
| `text.py` | 流式文本合并、发送模式、富文本/Post |
| `special.py` | 联系人消歧与交付物卡片 |
