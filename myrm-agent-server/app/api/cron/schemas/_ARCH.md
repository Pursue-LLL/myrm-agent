# app/api/cron/schemas 子包架构

定时任务 API 的请求/响应契约。按 API 区域分模块，`__init__.py` 聚合全部 41 个模型，`app.api.cron.schemas` 导入路径不变。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `__init__.py` | 子域出口 | 聚合 re-export 全部 cron 模型 | — |
| `delivery.py` | 核心 | 交付目标与其测试请求/响应 | ✅ |
| `triggers.py` | 核心 | 调度、监控、失败告警与各类触发器（事件/系统事件/Webhook）的创建与响应，含事件派发请求 | ✅ |
| `jobs.py` | 核心 | 任务创建/更新、任务与运行响应、链断裂与完整性校验、列表响应（含字段校验） | ✅ |
| `usage.py` | 核心 | 用量统计（总览 / 按天 / 按任务 / 按模型） | ✅ |
| `operations.py` | 核心 | 心跳开关、前置条件检查与连接器健康 | ✅ |

## 依赖关系

- 上游：`pydantic`
- 下游：`app/api/cron/*` 路由、`app/core/cron/*`（构造响应）
